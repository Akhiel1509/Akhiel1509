### 🤖 Multi-Agent Salesforce Development Pipeline

<a href="https://github.com/Akhiel1509/salesforce-agent-office">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Akhiel1509&repo=salesforce-agent-office&theme=nord&border_color=7dd3fc&title_color=7dd3fc&icon_color=7dd3fc&text_color=e2e8f0" alt="salesforce-agent-office" />
</a>

A multi-agent system built on the Anthropic Claude API that simulates a full Salesforce development team (BA, PM, 2 developers, QA, admin). It routes tickets through a deterministic workflow, deploys via the Salesforce CLI behind a human-in-the-loop approval gate, and verifies every deployment against live Tooling API and SOQL queries.

| Layer | Technology |
|-------|------------|
| AI / Orchestration | Anthropic Claude API, role-specific prompting, structured JSON output |
| Backend | Python, Flask |
| Salesforce | Salesforce CLI (sf), Tooling API, SOQL, Apex, LWC, Flows |
| Monitoring UI | Phaser.js "virtual office" |

🔗 [Code](https://github.com/Akhiel1509/salesforce-agent-office)
